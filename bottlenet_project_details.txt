SECTION 6 — FAILURE MODES OBSERVED
--------------------------------------------------------------------------------
- Confusion matrix weaknesses:
  High False Negative (FN) rate when using a static 0.5 decision threshold without quantile post-processing. Because the bottleneck class is sparse (~14.66%), raw uncalibrated 0.5 probability outputs under-predict bottleneck links relative to the true top-10% congestion threshold.

- Class imbalance issues:
  Severe class imbalance exists across the dataset (3,026,219 normal links vs 519,898 bottleneck links, an 85.34% vs 14.66% ratio). While loss weighting (pos_weight = 6.13) mitigated majority class dominance during loss gradient updates, uncalibrated softmax decision boundaries at 0.5 degrade precision and recall without dynamic quantile thresholding.

- Early training run problems (ROC-AUC < 0.5 in first 3 runs):
  The first 3 initial training runs on 2026-09-19 recorded ROC-AUC scores below 0.5 (Run 1: 0.427, Run 2: 0.497, Run 3: 0.425). This occurred because early scripts attempted to train on a single isolated 12-timestep snapshot (207 nodes total) without mini-batching over all timesteps, used unweighted CrossEntropy loss, lacked batch normalization and residual skip connections, and suffered from learning rate instability with initial loss spiking > 300.

- Single-window training limitations:
  Single-window snapshot training lacks rolling temporal feature context (rolling 15-minute means, standard deviations, and drop ratios), causing the GNN to overfit to static speed noise of one snapshot instead of learning spatial-temporal bottleneck propagation.

- Cold-start sensor issues:
  Sensors with unobserved speeds or missing historical records lack baseline median values and spatial neighbor connections, forcing feature engineering to fall back to global medians (30.0 mph) and zeroed drop ratios.

- Convergence instability:
  Validation loss fluctuated between 0.604 and 0.685 after Epoch 3 due to aggressive fixed learning rate (0.002) and graph mini-batch variance across rolling windows, necessitating ReduceLROnPlateau learning rate scheduling.

SECTION 8 — GENERATE ABSTRACT
--------------------------------------------------------------------------------
BottleNet solves the critical problem of real-time traffic bottleneck identification and congestion propagation analysis across urban road networks. The framework integrates an iterative weighted voting baseline with a 3-layer residual Graph Convolutional Network (GNN) trained on 17,131 rolling window snapshots extracted from the METR-LA dataset. BottleNet achieved a test ROC-AUC of 0.809, a test accuracy of 83.65%, and robust directional inference verification where low speeds (<= 20 mph) yielded 100% bottleneck detections while free-flow speeds (>= 50 mph) produced 0% bottlenecks.
